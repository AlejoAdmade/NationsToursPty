# Nation Tours PTY Demo V0.2

Demo estática lista para subir a GitHub Pages.

## Qué incluye
- Homepage turística premium
- Sección de tours
- Presentación de Ana Lorena
- Métodos de pago
- Redes sociales
- Sección de recuerdos
- Mockup de panel para subir fotos y gestionar álbumes
- Toggle ES/EN

## Publicación en GitHub Pages
1. Crea un repositorio nuevo.
2. Sube `index.html`, `.nojekyll` y `README.md` a la raíz.
3. Entra a Settings > Pages.
4. Selecciona Deploy from a branch.
5. Escoge `main` y `/root`.

## Nota
Esta versión es una demo visual. El panel administrativo es un mockup y todavía no está conectado a Cloudflare R2, D1 ni Workers.
