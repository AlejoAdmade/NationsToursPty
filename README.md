# Nation Tours PTY — Demo V0.4 (Sitio inicial)

Sitio estático multipágina listo para GitHub Pages. Subir el contenido completo de este ZIP a la raíz del repositorio.

## Páginas
- `index.html` — Inicio
- `tours.html` — Catálogo de experiencias de muestra
- `tour-ciudad.html`, `tour-naturaleza.html`, `tour-privado.html` — Fichas individuales y mini galerías
- `kids.html` — Nation Tours PTY KIDS
- `contacto.html` — Contacto, redes sociales, pagos y solicitud de reserva por WhatsApp

La galería privada de recuerdos y el panel administrativo **se han retirado** de esta versión.

## Formulario de reservas
El formulario de `contacto.html` es funcional como **mensaje prellenado de WhatsApp**. No registra datos en una base de datos, no envía correos automáticamente, no procesa pagos y no confirma reservas por sí mismo. La solicitud debe enviarse desde WhatsApp por el visitante.

## Publicación
GitHub Settings > Pages > Deploy from a branch > main > /(root). No requiere compilación.
